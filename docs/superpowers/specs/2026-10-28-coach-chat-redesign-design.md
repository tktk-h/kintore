# AIコーチのチャット画面の作り直し 設計書（2026-10-28）

## 困っていること
- 「変更して」と頼むたびに大きなメニュー案のカードが積み重なり、会話が埋もれる。長くスクロールしないといけない
- 前の案に戻って見るのが大変。直した案と1つ前の案で、どこが変わったか分からない
- どの案で「反映する」を押せばいいか分かりにくい
- 自分の吹き出しとAIの吹き出しが似た色で、間隔も狭く、自分の発言を探すのに時間がかかる

## 方針
案をチャットから分ける。チャットには文だけを流し、案は1行の入口にする。案は専用の画面で、前の案との違いを見ながら確認・反映する。

## 1. チャット画面（`/coach`）
- 自分の吹き出し：オレンジで塗り、右寄せ（幅は最大8割ほど）。文字は濃い色
- AIの吹き出し：濃い灰色、左寄せ
- 吹き出しの間を今より広くあける（同じ人が続くときより、話す人が変わるときを広く）
- 相談への答えなど、文だけの返事は今までどおり全文を吹き出しで出す
- 案を作った返事は、AIのひとことを吹き出しで出し、その下に**案の1行**を出す（今の大きなカードは出さない）
  - 表示：「案N · 4日 · 16種目」（1つ前の案と比べられるときは「案N · 変更 12か所」）、右に「未反映」または「反映済み」
  - Nは、このチャットに出た案の通し番号（古い順に1から）
  - まだ反映していない一番新しい案の1行は、オレンジの枠で目立たせる
  - 押すと案の画面が開く
- 考え中の下の「1〜2分かかることがあります」は「10秒ほどかかります」に直す

## 2. 案の画面（`/coach/proposal/:messageId`）
- 左上に戻るボタン（チャットに戻る）。下のタブは「AIコーチ」が選ばれた表示のまま
- 上に「◀ 案N / 全部の数 · 対象の日付の範囲 ▶」。矢印で、このチャットのほかの案に切り替える（URLを置き換える。端では矢印を押せない見た目にする）
- 中身は今のメニュー案カードと同じ（日ごとにたためる、1種目1行、部位タグ、約N分、理由、問題点、軽めの週の印、種目を押すと詳細と編集）
- **前の案との違い**（比べる相手は、このチャットで1つ前に出た案）
  - 重さ・回数・セット数が変わった所はオレンジにして、横に前の値を小さく出す（例：「62.5kg ←60」）
  - 同じ枠で種目が替わったものには「入れ替え」、新しく入った種目には「新」の印を付ける
  - 外した種目は、その日の下に「外した種目」として薄く並べる。日ごと外れたときは、一番下に「外した日」として日付と種目を薄く並べる
  - 画面の上に「オレンジ＝案N-1から変わった所」と1行で説明する
  - 案1、または1つ前の案と対象の日付が1日も重ならないときは比べない（「前の案と対象の週が違うので比べていません」と出す）
- 一番下に「この案を反映する」（反映済みなら「反映済み」）。今の反映の動き（過ぎた日は除く、既存の予定を置き換えるときの確認）はそのまま
- 古い案も反映できる（今と同じ）

## 3. 違いの見つけ方（`src/coach/diff.ts`）
- 種目は「日付＋枠（slot）」で前の案と結びつける。枠がない種目は「日付＋種目ID」で結びつける
- 結果は種目ごとに：変わらない／変わった（どの項目が、前の値はいくつか）／入れ替え（前の種目ID）／新。あわせて、日ごとに外した種目の一覧
- 「変更 Nか所」は、変わった・入れ替え・新・外した種目の数の合計（1種目で重さと回数が両方変わっても1か所）
- 画面に関係しない純粋な関数にして、テストで確かめる

## 4. やらないこと
- 案を3つ以上並べて比べる
- 反映済みの予定と比べる（必要になったら後で足す）
- データの形は変えない（案は今までどおりチャットのメッセージに入っている）

## 5. 作る順番（できた順に公開）
1. 吹き出しの見た目（色・寄せ・間隔）と、考え中の文の修正
2. 違いの見つけ方（`diff.ts`）とテスト
3. 案の画面（今のカードの中身を移す）と、チャットの1行
4. 案の画面に、前の案との違いの表示と、案の切り替えを足す
