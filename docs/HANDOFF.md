## これまでに作ったもの

### フェーズ1a：記録の基盤（完成）
- トレーニング記録（重量×回数／回数のみ／時間・距離）、チェックボックスで完了、＋−で数値変更
- 休憩タイマー（自動開始・画面を光らせる・画面が消えない・アプリを閉じても正しい）
- トレーニングの一時停止・キャンセル、種目ごとのきつさ・メモ、終了時の調子・満足度
- 体の記録（体重・体脂肪率・写真・写真の比較）
- カレンダー（ホームのカード＋全画面 `/calendar`。部位の色の棒、今日ボタン）、日付ページ
- 種目データベース（定番64種目・動きの種類・部位・初心者の目安の重さ）、マイメニュー
- バックアップ（書き出し・読み込み）、設定（重量の刻み幅、ダンベルの刻み幅＝既定1kg）
- すべてのカードをたためる、バージョン表示（ホーム下部と設定）

### フェーズ1b：AIコーチ（ほぼ完成）
- プロフィールの聞き取り（目標・経験・週の回数・時間・曜日・器具・ケガ・今の重量・分割法）
- チャットで「来週のメニューを作って」等 → **アプリが骨組み（分割法・枠・量）を決め、AIが種目を選ぶ** → アプリが重さを計算・チェック → メニュー案カード → 「反映する」で予定に入る
- 重さ：記録 → プロフィールの重量 → 種目ごとの目安 の順。きつさ（1〜5）で上げ下げ、デロード
- チャットで「負荷を上げて」「軽くして」等を頼むと反映（前の案を基準に変える）
- メニュー案・今日の予定・カレンダーの予定の種目を押すと詳細と編集（セット・回数・重さ・休憩・入れ替え・外す）
- 一覧は1種目1行の見やすい形（「10×3 60kg」、日ごとにたためる、部位タグ・約N分）
- Geminiが混んでいる／上限に達したときは別のFlashモデルに自動で切り替え

設計の詳細は `docs/superpowers/specs/2026-10-13-phase1b-ai-coach-design.md`（メニューの決め方の根拠・ルール表あり）。
